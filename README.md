# HOSTELSPHERE 🏨

**HOSTELSPHERE** is a web-based Smart Hostel Operations Platform designed to simplify and digitize everyday hostel management.

It provides students and hostel administrators with a centralized platform to manage essential hostel services and improve communication.

## Features

* 📝 Complaint Management
* 🛏️ Room Allocation
* 🚪 Gate Pass Requests & Approval
* 🍽️ Mess Menu
* 🧺 Laundry Services
* 📢 Hostel Announcements
* 💰 Fee Analytics
* 🔎 Lost & Found
* 🚨 Emergency / SOS
* 💡 Feedback & Suggestions
* ❓ FAQs
* 📄 Digital Proof Upload

## Tech Stack

* **Frontend:** React, Vite, TypeScript
* **Styling:** Tailwind CSS
* **Backend:** Supabase
* **Database:** PostgreSQL
* **Authentication:** Supabase Auth
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## Getting Started

```bash
git clone <repository-url>
cd hostelsphere
npm install
npm run dev
```

Create a `.env` file and configure the required Supabase credentials before running the application.

## Project Objective

The goal of HOSTELSPHERE is to replace manual and fragmented hostel processes with a centralized digital platform that makes hostel services **faster, simpler, and more accessible**.
